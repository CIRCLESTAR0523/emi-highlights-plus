# EMI Highlights Plus

収納の中から、レシピに必要な素材をすぐ見つけられるようにするEMIアドオンです。Recipe Tree／Crafting Modeの必要素材表示を、対応する収納・変換画面へ広げます。

- **Sophisticated Storage／Backpacks：** 必要素材を水色でハイライト。
- **ProjectE／Project Expansion／AE2：** 検索や普段の操作を保ちながら、必要素材を上に表示。
- **Arcane Transmutation Tablet：** 学習済みアイテムと利用可能なEMCを材料判定へ反映。

## 使い方

**Minecraft 1.21.1・NeoForge 21.1.234以降・Java 21・EMI 1.1.24以降**が必要です。使用する連携先Modと一緒にクライアントへ導入してください。サーバーへの導入は不要です。

EMIで対象レシピのCrafting Modeを有効にし、対応する画面を開くと機能します。Refined Storage対応は実験的で、ゲーム内での動作は未確認です。

旧EMI Container Highlightsから更新する場合は、先に旧JARを外してください。設定の移行方法はリリースノートをご覧ください。
