# EMI Highlights Plus

Find the materials you need without searching through your storage. This EMI add-on brings Recipe Tree and Crafting Mode material highlights to supported storage and transmutation screens.

- **Sophisticated Storage / Backpacks:** highlights required materials in cyan.
- **ProjectE / Project Expansion / AE2:** moves required materials to the top while preserving search and normal controls.
- **Arcane Transmutation Tablet:** includes learned items and available EMC in EMI's material checks.

## Getting started

Requires **Minecraft 1.21.1, NeoForge 21.1.234+, Java 21, and EMI 1.1.24+**. Install on your client alongside the integration Mods you use; no server installation is needed.

Enable EMI's Crafting Mode for your recipe, then open a supported screen. Refined Storage support is experimental and has not been verified in-game.

Updating from EMI Container Highlights? Remove the old JAR first; see the release notes for settings migration.
