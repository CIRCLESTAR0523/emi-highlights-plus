# EMI Highlights Plus 0.2.1 Release Notes

- Release type: Stable patch
- Publication date: 2026-09-24
- Previous version: 0.2.0

## Overview

Version 0.2.1 makes EMI Crafting Mode highlights easier to read across supported storage and transmutation screens. Required-item overlays now use consistent layering, while stack counts and terminal symbols remain visible above the cyan highlight.

## Highlights

- Added the missing cyan required-item overlay to Refined Storage Grid and Wireless Grid.
- Kept stack counts readable above highlights in Refined Storage, AE2, ProjectE, Project Expansion, Sophisticated Storage, and Sophisticated Backpacks screens.
- Preserved native search, sorting, clicks, configuration, and world or player data.

## Supported Environment

- Minecraft: 1.21.1
- Loader: NeoForge 21.1.234 or later
- Java: 21
- Required: EMI 1.1.24 or later
- Optional integrations: Sophisticated Core/Storage/Backpacks, ProjectE, Project Expansion, Applied Energistics 2, and Refined Storage

## Who Should Update

Update from 0.2.0 if you use any supported integration and want consistent highlight and count layering. This is a non-breaking replacement for 0.2.0.

## Update Instructions

1. Close Minecraft.
2. Remove `emi_highlights_plus-0.2.0.jar`.
3. Install `emi_highlights_plus-0.2.1.jar`. Do not keep both versions together.

No configuration, world, or player-data migration is required.
