# EMI Highlights Plus 0.2.1 Known Issues

No release-blocking issue specific to 0.2.1 is known at publication preparation time.

## Compatibility Scope

- Compatibility is limited to the supported Mod and version ranges listed in the release notes. Other Mods, versions, and custom screens are not guaranteed.
- If an optional integration causes a problem, disable that integration in `config/emi_highlights_plus-client.toml` and report it at https://github.com/CIRCLESTAR0523/emi-highlights-plus/issues.

## Update Note

- Remove the 0.2.0 JAR before installing 0.2.1. Do not install both versions together.
- This update does not migrate or alter world or player data.
