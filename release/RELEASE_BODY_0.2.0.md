# EMI Highlights Plus 0.2.0

EMI material highlights and priority ordering for supported storage and transmutation screens.

- Cyan highlights in Sophisticated Storage / Backpacks.
- Required-material priority in ProjectE / Project Expansion / AE2.
- Arcane Transmutation Tablet material checks include learned items and available EMC.

**Requires:** Minecraft 1.21.1, NeoForge 21.1.234+, Java 21, EMI 1.1.24+. Client installation; no server installation needed.

**Notes:** Refined Storage support is experimental and has not been tested in-game. Remove the old EMI Container Highlights JAR before updating; settings require manual migration.

対応する収納・変換画面で、EMIの必要素材を見つけやすくするModです。

- Sophisticated Storage／Backpacksの必要素材を水色表示。
- ProjectE／Project Expansion／AE2で必要素材を優先表示。
- Arcane Transmutation Tabletの学習済みアイテムとEMCを材料判定へ反映。

**必要環境：** Minecraft 1.21.1、NeoForge 21.1.234以降、Java 21、EMI 1.1.24以降。クライアントへ導入してください。

**注意：** Refined Storage対応は実験的で実機未確認です。旧EMI Container HighlightsのJARを外して更新してください。設定の移行は手動です。
