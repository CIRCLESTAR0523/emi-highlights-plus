# EMI Highlights Plus 0.2.1

This patch makes EMI Crafting Mode highlights easier to read across supported screens. Refined Storage Grid and Wireless Grid now receive the cyan required-item overlay, while stack counts and terminal symbols stay visible above highlights in supported integrations.

このPatchでは、対応画面のEMI Crafting Modeハイライトを見やすくしました。Refined StorageのGrid／Wireless Gridにも水色の必要素材overlayを追加し、対応連携のアイテム個数やterminal記号がハイライトより前面に表示されます。

## Update / 更新

- Remove `emi_highlights_plus-0.2.0.jar` and install `emi_highlights_plus-0.2.1.jar`.
- `emi_highlights_plus-0.2.0.jar`を外し、`emi_highlights_plus-0.2.1.jar`へ置き換えてください。
- No configuration, world, or player-data migration is required. / 設定、world、player dataの移行は不要です。

## Environment / 対応環境

- Minecraft 1.21.1
- NeoForge 21.1.234+
- Java 21
- Required: EMI 1.1.24+
- Optional: Sophisticated Core/Storage/Backpacks, ProjectE, Project Expansion, Applied Energistics 2, Refined Storage
