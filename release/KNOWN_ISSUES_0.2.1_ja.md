# EMI Highlights Plus 0.2.1 既知の問題

公開準備時点で、`0.2.1`固有の公開を妨げる既知の問題はありません。

## 互換性の範囲

- 対応範囲はリリースノートに記載したModとversionに限ります。その他のMod、version、独自画面への対応は保証しません。
- 任意連携で問題が起きた場合は、`config/emi_highlights_plus-client.toml`で該当連携を無効にし、https://github.com/CIRCLESTAR0523/emi-highlights-plus/issues へ報告してください。

## 更新時の注意

- `0.2.1`を導入する前に`0.2.0` JARを外し、両versionを同時に導入しないでください。
- この更新はworldおよびplayer dataを移行・変更しません。
