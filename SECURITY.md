# Security Policy

## Supported versions

Security support begins when EMI Highlights Plus 0.2.x is published for Minecraft 1.21.1 and NeoForge. Unpublished development artifacts and older source snapshots are not public release channels.

## Reporting a vulnerability

Do not include exploit details, private data, tokens, or sensitive logs in a public Issue.

Use [GitHub's private vulnerability reporting](https://github.com/CIRCLESTAR0523/emi-highlights-plus/security/advisories/new) for security issues. Ordinary bugs and compatibility problems can be reported through GitHub Issues.

Support is best effort. Receipt of a report does not promise a response or fix date.

# セキュリティポリシー

## 対応version

Minecraft 1.21.1／NeoForge向けEMI Highlights Plus 0.2.xの公開後からセキュリティ対応を開始します。未公開の開発成果物や過去のsource snapshotは、公開releaseの配布経路ではありません。

## 脆弱性の報告

悪用手順、個人情報、token、機密性のあるlogを公開Issueへ書かないでください。

セキュリティ上の問題は[GitHubの非公開脆弱性報告](https://github.com/CIRCLESTAR0523/emi-highlights-plus/security/advisories/new)からご連絡ください。通常の不具合や互換性問題はGitHub Issuesで受け付けます。

サポートはbest effortであり、返信日や修正日を保証しません。
